<role>
You turn the results of an Ollama benchmark into a plain-language visual report. The reader is not technical. They want to see each model, how it did on each task, and a few details. They do not want jargon, formulas or long text.
</role>

<what_you_get>
The person ran a script named bench.py on their Mac. The script tested every text model they have downloaded in Ollama on six fixed tasks. It wrote a file named results.json inside a folder named run-YYYYMMDD-HHMMSS, next to bench.py. The person attaches that results.json to this chat. A second file, results.csv, holds a flat copy and is optional. You do not need the outputs folder.

If the person has not attached results.json, do not guess. Say this in two or three lines and stop:
  1. Keep Ollama running and run: python3 bench.py (Python 3, no extra packages, macOS).
  2. Expect one to two minutes per model, longer for large ones. Optional settings are environment variables: BENCH_REPS (repeats per task, default 2), BENCH_CTX (context window, default 8192), BENCH_COOLDOWN (seconds of rest between models, default 30), BENCH_MODELS (comma list of name pieces to test), BENCH_THINK (set to 1 to leave thinking mode on), BENCH_HOST (Ollama address).
  3. For chip temperatures, install macmon first (brew install macmon), then run again. Attach the new results.json here.
</what_you_get>

<the_six_tasks>
bench.py runs these tasks on every model, in this order. Models run from smallest to largest. Temperature 0 and a fixed seed make repeat runs match. A random prefix on each prompt defeats prompt caching.
  short_qa         Explain unified memory in two sentences. Not scored. Timed only.
  reasoning        Two-trains word problem. Scored: the final line must read ANSWER: 6:00 pm.
  code             Write a Python function is_balanced(s). Scored: it runs in a sandbox against eight test cases.
  instructions     Write exactly 5 bullets, each under 12 words, no commas. Scored by a script.
  long_context     A 140-entry log, then: what is the access code in Entry 87? Scored: the code must match.
  long_generation  Write a 600 word essay on how a heat sink and fan work. Not scored. Timed only. One run per model.
Each scored task runs settings.reps times (default two). Output caps in tokens: short_qa 120, reasoning 400, code 400, instructions 150, long_context 40, long_generation 800. A run that hits its cap has done_reason "length".
</the_six_tasks>

<results_json_format>
Top-level keys: started, finished, progress ("done" when the run completed), ollama_version, hardware, settings, prompts, models, rows, updated.
  hardware: chip, model_id, memory_gb, macos, gpu_cores, power, python
  settings: reps, num_ctx, temperature, seed, thinking, cooldown_s, temperature_source (null unless macmon was found)
  models: one object per model with name, size_gb, params, quant, family, mem_before, cold_load_s, loaded_size_gb, gpu_share_pct
  rows: one object per run with model, prompt, rep, correct (true, false or null for unscored tasks), ttft_s (seconds to the first word, can be null), wall_s, load_s, prompt_tokens, prefill_tps, gen_tokens, decode_tps, total_s, done_reason ("stop" or "length"), thermal_before, thermal_after (raw macOS notes), cpu_speed_limit_after, sensors (null, or a dictionary of metric name to {mean, max} for names that contain "temp" or "power"), mem_after {swap, free_pct}, and error (only when a run failed)
</results_json_format>

<writing_rules>
These rules apply to every word you write for the page and for your reply.
  Use clear, simple language. Use short sentences. Use active voice. Say "you" and "your" where the page speaks to the reader.
  Be spartan and informative. Each sentence carries one fact.
  Use plain words. Say "words per second", not tokens per second. Say "wait before the first word", not time to first token. Never use these words on the page: token (except in the fixed note about the 0.75 estimate), quantization, prefill, decode, latency, throughput, context window, TTFT.
  Never use an em dash. Use a period or a comma. Never use semicolons. Never ask a rhetorical question.
  Avoid metaphors, cliches, hype and filler. Avoid the words: very, really, just, actually, basically, however, moreover, furthermore, powerful, boost, robust, seamless.
  Do not use markdown inside the HTML. Do not add warnings or disclaimers beyond the notes below.
  Every claim must follow from facts.json, models.json or task_scores.json. Do not state a cause that the data does not show. Do not use outside knowledge about a model except what its name or family makes certain.
  Compare only with the other models in this run.
  Treat two writing speeds within 5 percent of each other as equal. Run to run noise reaches about 1.5 percent.
</writing_rules>

<verdicts>

Build each verdict from this order of facts:
  First sentence: where the model stands. Use quality (answers right out of quality_max), then speed rank, then size.
  Second sentence: what it fails or what it costs. Name each failed task in plain words: "the word problem", "the code task", "the rules task", "the long log search". Name a cost only if the data shows it: a long wait on the long log, high memory, or megabytes moved to disk.
Rules for special cases:
  A model with full quality and the highest speed among the full-quality models gets the words "Best all-round pick." Use these words for one model only. If two full-quality models are within 5 percent on speed, pick the one with the shorter wait on the long log.
  Two models listed together in facts.duplicates have the same size, parameters and compression. Say "Same model as X under another name." for both, plus their results.
  A model listed in facts.not_timed_fairly has no speed or long log wait. Say why in plain words: its answers were too short, or the long log was cut short. Say it reads images only if its name or family makes that certain (for example moondream). Otherwise say its answers were too short to score or time fairly.
  If a miss appears in facts.length_limit_misses, say the miss came from running out of room to finish and not from a wrong answer.
  If swap_mb is above zero for a model, say your Mac moved that many megabytes to disk, and give min_free_pct as the lowest free memory.
  Do not use the words "best" or "worst" except in the "Best all-round pick." phrase. Do not write numbers into verdicts except counts that already appear on the card or a swap figure.
</verdicts>

#!/usr/bin/env python3
"""Turn a bench.py results.json into the two data tables the report page reads.

Usage:  python3 build_data.py results.json [outdir]
Writes: models.json, task_scores.json, facts.json   (no verdicts yet, Claude adds them)
"""
import json
import os
import re
import statistics
import sys
from collections import defaultdict

src = sys.argv[1]
out = sys.argv[2] if len(sys.argv) > 2 else "."
os.makedirs(out, exist_ok=True)
d = json.load(open(src))

WORDS_PER_TOKEN = 0.75          # estimate, stated on the page
MIN_TOKENS_FOR_SPEED = 40       # shorter answers give noisy speed numbers
TASKS = [  # key, plain label, order
    ("short_qa", "Quick question", 1),
    ("reasoning", "Word problem", 2),
    ("code", "Write code", 3),
    ("instructions", "Follow rules", 4),
    ("long_context", "Long log search", 5),
    ("long_generation", "Write essay", 6),
]
SCORED = {"reasoning", "code", "instructions", "long_context"}

rows_all = d["rows"]
rows = [r for r in rows_all if not r.get("error")]
errors = [(r["model"], r["prompt"], r.get("error")) for r in rows_all if r.get("error")]
meta = {m["name"]: m for m in d["models"]}
order = [m["name"] for m in d["models"] if any(r["model"] == m["name"] for r in rows)]
ram_gb = d["hardware"].get("memory_gb")


def wtps(rs):
    """Token-weighted decode speed over runs with enough tokens."""
    rs = [r for r in rs if (r.get("gen_tokens") or 0) >= MIN_TOKENS_FOR_SPEED and r.get("decode_tps")]
    if not rs:
        return None
    return sum(r["gen_tokens"] for r in rs) / sum(r["gen_tokens"] / r["decode_tps"] for r in rs)


def swap_mb(s):
    m = re.search(r"used = ([\d.]+)M", s or "")
    return float(m.group(1)) if m else 0.0


def median(xs):
    return statistics.median(xs) if xs else None


bym = defaultdict(list)
for r in rows:
    bym[r["model"]].append(r)

# long_context prompt size per model, to spot models whose prompt was cut short
lc_tokens = {n: median([r["prompt_tokens"] for r in bym[n] if r["prompt"] == "long_context" and r.get("prompt_tokens")])
             for n in order}
typical_lc = median([v for v in lc_tokens.values() if v])

models_out, tasks_out, not_fair = [], [], []
for name in order:
    rs, m = bym[name], meta[name]
    byt = defaultdict(list)
    for r in rs:
        byt[r["prompt"]].append(r)

    quality = quality_max = 0
    for key, label, o in TASKS:
        tr = byt[key]
        if not tr:
            continue
        c = None
        if key in SCORED:
            c = sum(1 for r in tr if r.get("correct"))
            quality += c
            quality_max += len(tr)
        tw = wtps(tr)
        tasks_out.append({
            "model": name, "task": key, "task_label": label, "task_order": o,
            "runs": len(tr), "correct": c,
            "avg_s": round(sum(r["wall_s"] for r in tr) / len(tr), 2),
            "avg_words": round(sum((r.get("gen_tokens") or 0) for r in tr) / len(tr) * WORDS_PER_TOKEN),
            "words_per_s": round(tw * WORDS_PER_TOKEN, 1) if tw else None,
            "hit_limit": sum(1 for r in tr if r.get("done_reason") == "length"),
        })

    # fairness rules
    short_tokens = [r["gen_tokens"] for r in byt["short_qa"] + byt["reasoning"] if r.get("gen_tokens") is not None]
    answers_too_short = bool(short_tokens) and median(short_tokens) < 10
    prompt_cut = bool(lc_tokens.get(name) and typical_lc and lc_tokens[name] < 0.5 * typical_lc)
    w = wtps(rs)
    speed = None if (answers_too_short or w is None) else round(w * WORDS_PER_TOKEN, 1)
    lc = [r for r in byt["long_context"] if r.get("ttft_s") is not None]
    wait_long = None if (prompt_cut or answers_too_short or not lc) else round(sum(r["ttft_s"] for r in lc) / len(lc), 1)
    if speed is None or wait_long is None:
        not_fair.append({"model": name, "answers_too_short": answers_too_short, "prompt_cut": prompt_cut})

    sh = sorted((r["ttft_s"] if r.get("ttft_s") is not None else r["wall_s"]) for r in byt["short_qa"])
    wait_short = round(median(sh), 2) if sh else None

    mem = [r["mem_after"] for r in rs if r.get("mem_after")]
    peak_temp = None
    for r in rs:
        s = r.get("sensors") or {}
        for k, v in s.items():
            if "temp" in k and "power" not in k and v.get("max") is not None:
                peak_temp = v["max"] if peak_temp is None else max(peak_temp, v["max"])

    models_out.append({
        "model": name,
        "size_gb": m["size_gb"], "loaded_gb": m["loaded_size_gb"], "ram_gb": ram_gb,
        "compression": m["quant"], "cold_load_s": m["cold_load_s"],
        "words_per_s": speed,
        "speed_note": "Not timed fairly. Its answers were too short to time." if speed is None else None,
        "quality": quality, "quality_max": quality_max,
        "wait_long_s": wait_long,
        "wait_note": "No fair time. This model cut the long log short." if wait_long is None else None,
        "wait_short_s": wait_short,
        "min_free_pct": min(x["free_pct"] for x in mem) if mem else None,
        "swap_mb": max(swap_mb(x["swap"]) for x in mem) if mem else 0.0,
        "peak_temp_c": round(peak_temp, 1) if peak_temp is not None else None,
        "verdict": "",   # Claude writes this from the numbers
    })

# duplicates: same size, parameters and compression
groups = defaultdict(list)
for m in models_out:
    mm = meta[m["model"]]
    groups[(mm["size_gb"], mm.get("params"), mm["quant"])].append(m["model"])
duplicates = [g for g in groups.values() if len(g) > 1]

# misses caused by the length limit
limit_misses = [{"model": r["model"], "task": r["prompt"], "rep": r["rep"]}
                for r in rows if r["prompt"] in SCORED and not r.get("correct") and r.get("done_reason") == "length"]

therm_raw = set()
for r in rows:
    for k in ("thermal_before", "thermal_after"):
        t = r.get(k)
        if t:
            therm_raw.add(json.dumps(t, sort_keys=True))
    if r.get("cpu_speed_limit_after") not in (None, 100):
        therm_raw.add("cpu_speed_limit:" + str(r["cpu_speed_limit_after"]))
quiet = all(("No thermal warning level has been recorded" in s and "No performance warning level has been recorded" in s)
            for s in therm_raw if s.startswith("{")) and not any(s.startswith("cpu_speed_limit") for s in therm_raw)

facts = {
    "started": d.get("started"), "finished": d.get("finished"), "progress": d.get("progress"),
    "ollama_version": d.get("ollama_version"), "hardware": d["hardware"], "settings": d["settings"],
    "models_in_order": order, "typical_long_prompt_tokens": typical_lc,
    "not_timed_fairly": not_fair, "duplicates": duplicates, "length_limit_misses": limit_misses,
    "errors": errors, "has_temperature": any(m["peak_temp_c"] is not None for m in models_out),
    "macos_reported_no_heat_warnings": quiet,
    "ranks": {
        "by_quality": sorted(((m["quality"], m["model"]) for m in models_out), reverse=True),
        "by_speed": sorted(((m["words_per_s"], m["model"]) for m in models_out if m["words_per_s"] is not None), reverse=True),
        "by_long_wait": sorted(((m["wait_long_s"], m["model"]) for m in models_out if m["wait_long_s"] is not None)),
        "by_memory": sorted(((m["loaded_gb"], m["model"]) for m in models_out), reverse=True),
    },
}
json.dump(models_out, open(os.path.join(out, "models.json"), "w"), indent=1)
json.dump(tasks_out, open(os.path.join(out, "task_scores.json"), "w"), indent=1)
json.dump(facts, open(os.path.join(out, "facts.json"), "w"), indent=1)
print("wrote models.json, task_scores.json, facts.json in", out)
print(json.dumps(facts, indent=1))
</file>

/* Stand-in for the dashboard host and for d3. The page code below runs unchanged. */
var DATA = JSON.parse(document.getElementById('bm-data').textContent);
var dash = {
  colors: ['var(--bm-accent-base)'],
  data: function (id) { return { status: 'ok', data: DATA[id] }; },
  draw: function (name, fn) { document.querySelectorAll('[data-draw="' + name + '"]').forEach(fn); }
};
var d3 = {
  format: function (spec) {
    var dec = +spec.match(/\.(\d)f/)[1], group = spec.charAt(0) === ',';
    return function (v) { return group ? Number(v).toLocaleString('en-US', { minimumFractionDigits: dec, maximumFractionDigits: dec }) : Number(v).toFixed(dec); };
  },
  max: function (arr, fn) {
    var best;
    arr.forEach(function (x) { var v = fn ? fn(x) : x; if (v != null && !isNaN(v) && (best === undefined || v > best)) best = v; });
    return best;
  }
};

(function () {
  var root = document.querySelector('.bm');
  if (root) root.style.setProperty('--bm-accent', dash.colors[0]);

  var secs = function (v) { return v < 1 ? f2(v) : f1(v); };

  function el(tag, cls, text) {
    var n = document.createElement(tag);
    if (cls) n.className = cls;
    if (text != null) n.textContent = text;
    return n;

  function settle(host, ids) {
    var state = 'ok', out = {};
    ids.forEach(function (id) {
      var g = dash.data(id);
      out[id] = g.data;
      if (g.status === 'ok') return;
      if (g.status === 'loading') { if (state === 'ok') state = 'loading'; }
      else state = 'error';
    });
    host.classList.toggle('dash-skeleton', state === 'loading');
    if (state === 'error') {
      var w = el('div', 'bm-fail');
      w.append(el('i', 'bm-faildot'), document.createTextNode('Failed to load'));
      host.replaceChildren(w);
      return null;
    }
    if (state === 'loading') { host.replaceChildren(); return null; }
    return out;
  }

  function tipper(host) {
    var tip = el('div', 'bm-tip');
    tip.hidden = true;
    host.appendChild(tip);
    var pinned = null;
    function place(target) {
      var hr = host.getBoundingClientRect(), tr = target.getBoundingClientRect();
      var w = tip.offsetWidth, h = tip.offsetHeight;
      var x = tr.left - hr.left + tr.width / 2 - w / 2;
      x = Math.max(0, Math.min(x, host.clientWidth - w));
      var y = tr.top - hr.top - h - 6;
      if (y < 0) y = tr.bottom - hr.top + 6;
      tip.style.left = x + 'px';
      tip.style.top = y + 'px';
    }
    function show(target, title, lines) {
      tip.replaceChildren(el('div', 'bm-tip-t', title));
      lines.forEach(function (l) { tip.appendChild(el('div', null, l)); });
      tip.hidden = false;
      place(target);
    }
    function hide() { tip.hidden = true; }
    return {
      bind: function (target, title, lines) {
        target.tabIndex = 0;
        target.addEventListener('pointerenter', function () { show(target, title, lines); });
        target.addEventListener('pointerleave', function () { if (pinned !== target) hide(); });
        target.addEventListener('focus', function () { show(target, title, lines); });
        target.addEventListener('blur', function () { pinned = null; hide(); });
        target.addEventListener('click', function () { pinned = target; show(target, title, lines); });
      }
    };
  }

  function taskList(ts, onlyScored) {

      if (onlyScored && r.correct == null) return;
      if (!seen.has(r.task)) seen.set(r.task, r.task_label);
    });
    return Array.from(seen);
  }

  dash.draw('cards', function (host) {
    var d = settle(host, ['models']);
    if (!d) return;
    var wrap = el('div', 'bm-cards');
    d.models.forEach(function (m) {
      var c = el('div', 'bm-mc');
      c.appendChild(el('div', 'bm-mc-name', m.model));
      var s = el('div', 'bm-score');
      s.append(el('span', 'bm-big', String(m.quality)), el('span', null, 'of ' + m.quality_max + ' answers right'));
      c.appendChild(s);
      var segs = el('div', 'bm-segs');
      segs.setAttribute('role', 'img');
      segs.setAttribute('aria-label', m.quality + ' of ' + m.quality_max + ' answers right');
      for (var i = 0; i < m.quality_max; i++) segs.appendChild(el('i', 'bm-seg' + (i < m.quality ? ' on' : '')));
      c.appendChild(segs);
      var dl = el('dl', 'bm-dl');
      [
        ['Writing speed', m.words_per_s == null ? 'Not timed fairly' : f1(m.words_per_s) + ' words/s'],
        ['First reply, quick question', secs(m.wait_short_s) + ' s'],
        ['Wait on long log', m.wait_long_s == null ? 'Not timed fairly' : f1(m.wait_long_s) + ' s'],
        ['Memory in use', f1(m.loaded_gb) + ' of ' + m.ram_gb + ' GB'],
        ['Moved to disk', m.swap_mb > 0 ? f0(m.swap_mb) + ' MB' : 'None'],
        ['Size on disk', f1(m.size_gb) + ' GB'],
        ['First load', f1(m.cold_load_s) + ' s']
      ].forEach(function (p) { dl.append(el('dt', null, p[0]), el('dd', null, p[1])); });
      c.appendChild(dl);
      c.appendChild(el('p', 'bm-verdict', m.verdict));
      wrap.appendChild(c);
    });
    host.replaceChildren(wrap);
  });
